# User Module

User authentication and profile module for the Student Learning Platform.

## Tech Stack
- Frontend: React + Vite
- Backend: Java Spring Boot
- Database: MongoDB

## Features
- User registration
- User login
- User profile
- Basic user details
- Logout

## Structure
- `frontend/` - React application
- `backend/` - Spring Boot REST API

## Run
1. Start MongoDB.
2. Start the Spring Boot backend.
3. Start the React frontend.
4. Open the frontend URL shown by Vite.
