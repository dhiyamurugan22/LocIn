LockIn
🎓 Student Learning Hub

A unified learning platform designed for students to improve their programming, problem-solving, language skills, and academic knowledge in one place.

The main idea is to bring the useful features of platforms like GeeksforGeeks, LeetCode, and Duolingo into a single student-friendly application.

🚀 Project Overview

Students often use multiple applications and websites to learn different skills.

For example:

- GeeksforGeeks → Programming concepts and tutorials
- LeetCode → Coding problems and problem-solving
- Duolingo → Language learning & Sentence Translation

Instead of switching between multiple platforms, this project provides a single learning dashboard where students can access different learning resources and track their progress.

🎯 Objectives

- Provide students with a centralized learning platform
- Step-by-step guided onboarding (Sign In ➔ Skill Analysis ➔ Algorithm Test & Gate)
- 80% Algorithm Mastery Requirement before unlocking advanced courses & practice questions
- Integrated Sentence & Text Translator in Settings
- Improve programming and problem-solving skills
- Track learning progress with streak and XP gamification

✨ Key Features

1. 📚 Guided Onboarding & Skill Assessment
   - Step 1: Sign In / Sign Up Gate
   - Step 2: Background Analysis & Skill Profiler
   - Step 3: Branching Path (Beginner algorithm essentials vs Non-Beginner diagnostic test)
   - Step 4: Algorithm Qualification Test (10 questions covering Big-O, sorting, BST, graphs)
   - Step 5: 80% Passing Gate requirement to unlock courses and practice questions

2. 💻 Coding Practice & Interactive Runner
   - LeetCode / GFG style problem solver with difficulty filters and test case verification.

3. 🌎 Integrated Sentence & Text Translator (Settings)
   - Built into Settings (located beside the student profile avatar in header).
   - Translates sentences, problem descriptions, and explanations into target languages.

4. 📊 Student Dashboard & Streak Analytics
   - Visualized study hours and problem-solving output via Recharts.
   - 7-day streak tracker and XP progress indicators.

5. 🤖 AI Doubt Solver & Assistant
   - Interactive AI chat bot for instant coding help and concept breakdowns.

🛠️ Technologies & Stack

- **Frontend**: React.js, Vite, React Router DOM, Recharts, Lucide React icons
- **Backend Microservices**: Spring Boot (User Auth, AI Assistant, Algorithm Learning)

⚡ Quick Start (Running Locally)

1. Install Dependencies:
   ```bash
   npm.cmd install
   ```

2. Start Development Server:
   ```bash
   npm.cmd run dev
   ```
   Open `http://localhost:3000` in your browser to access LockIn Student Hub!

3. Build Production Bundle:
   ```bash
   npm.cmd run build
   ```
